# Workdesk

一个离线的像素风个人工作台。用日历安排任务，记录每日完成情况，追踪月度 KPI。

## 下载试用

前往本仓库的 **Releases**，下载 `workdesk-v1125.zip`，解压后运行 `workdesk-v1125.exe`。适用于 Windows 10/11，使用系统 .NET Framework 4.x，无需注册或联网。

试用包不包含作者的任务、KPI 或其他个人数据。

## Windows 功能

- 250×300 置顶窗口，可拉高至 600。
- 直接输入临时任务；勾完成、圈部分完成、叉取消。
- 部分完成后显示剩余数量，全部完成后从首页隐藏。
- 日历选择日期、批量安排、编辑及删除单日任务。
- 月度 KPI 彩虹进度条；任务名称匹配时自动累计。
- 未完成清单，长按拖动可重新加入今日。
- 九小时计时，下班前半小时显示像素风日报提醒。
- 本地数据、自动备份、导入导出，可选开机启动。

数据保存在 `%LOCALAPPDATA%\PixelWorkbench`，不随程序包上传或分发。

## Windows 构建

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
```

生成 `像素工作台.exe`。所需图标和头像保存在 assets.json 中，构建时自动还原并嵌入程序，无需额外依赖。
